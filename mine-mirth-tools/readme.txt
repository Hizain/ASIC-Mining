=== Mine Mirth Tools Showcase ===
Requires at least: 6.0
Requires PHP: 7.4
Stable tag: 1.0.0
License: GPLv2 or later

Shows your free mining calculators and tools as a card grid with "All Tools / Available Now / Coming Soon" filter tabs. Matches the Mine Mirth theme in light and dark mode.

== Use ==

Put [minemirth_tools] on any page.

Options:
* [minemirth_tools show="available"]  only live tools
* [minemirth_tools show="soon"]       only upcoming tools
* [minemirth_tools tabs="no"]         hide the filter tabs
* [minemirth_tools heading="no"]      hide the title and intro

== Settings › Tools Showcase ==

* Edit the title, intro, second line and button labels.
* Add, edit, reorder (↑ ↓) or remove tools. For each tool: name, page link, status (available / coming soon), colour, icon, badge, tags, description and an optional "Featured" ribbon.
* When a tool goes live, set it to "Available now" and paste its page link. A tool without a link always shows as coming soon.
* Icons are Font Awesome free icons (for example fa-calculator, fa-bolt, fa-chart-line); browse them at fontawesome.com.
